# 复合极端事件识别

## 已实现的能力

模块 `compound_detection.py` 逐时间片识别高温＋低氧、高温＋高酸度、低氧＋高酸度及三要素复合异常，再使用真实 Ocetrac 组织与追踪事件。默认单要素、复合持续条件均为 **1 个时间片**。

历史月均到近期日均的统一入口为 `evolution.py`；安装、算法版本、交接规则和完整示例见 [Ocetrac 演化模块](OCETRAC_EVOLUTION.md)。

- 同时型：同一时刻、同一水平格点、同一深度有多个已成立的单要素异常。
- 持续叠加型：上述重叠在固定格点、深度连续达到指定时间步数。
- 双要素默认包含三要素共现区域；`--exclusive-pairs` 将双要素限制为第三要素已知且非异常的位置。
- 支持共同日尺度、共同月尺度及带明确区间的月／日交接；不把月均 pH 复制成日均。
- 每种组合输出共同有效掩膜、重叠掩膜、持续事件掩膜、连通域编号、事件表与空间边界。
- 输出区域 LMF、样本数、时间区块自助法区间和区块置换检验。时间支持不足时省略区间和检验。

本模块是 Python 离线计算入口，不改变前端 mock 数据与运行按钮。

## 输入约束

输入为已经预处理的 NetCDF 或 `xarray.Dataset`，具有 `time/depth/latitude/longitude` 四个一维坐标。每个变量按这四个维度排列，维度顺序会自动规范化。

| 变量 | 标准单位 | 异常方向 |
|---|---|---|
| thetao | degrees_C | 高于阈值 |
| o2 | mmol m-3 | 低于阈值 |
| ph | 1 | 低于阈值 |

选择两个变量即可做双要素；三要素必须三变量都存在。多个文件空间/深度坐标必须完全相同，冲突值会报错，不静默覆盖。

日均时间须统一到 UTC 当天零点。缺少日期会插入 `NaN`，中断持续段，不跨缺失日期合并。日频请求通过每变量有实际数据的日期间隔检查拒绝月均/稀疏数据；不足两个有效日期时会提示无法确认原生频率。

月均输入须每变量每月最多一个时间片。完整月份时间轴补齐后，月份内部的不同代表日会规范到月初；不同文件若在同月使用不同代表日，应先对齐月坐标再加载。历史日均高温/氧事件与月均酸化匹配前，须在上游明确完成日事件向月状态的聚合；本模块不会直接平均原始日数据来代替事件聚合。

## 算法流程

1. 检查变量、单位、空间网格、深度及时间频率，形成完整时间坐标。
2. 复用单要素阈值算法：温度 P90，氧/pH P10，或用户指定绝对阈值。百分位仍按日历月分组，尚非逐日移动窗口气候态。没有指定基准期时使用输入时段，质量报告明确提示。
3. 默认保留每个时间片的单要素异常，不强加连续五天。只有用户显式指定大于 1 的持续步数时，才使用旧的固定格点连续筛选；缺测不能合并。
4. 单要素事件中的正常短缺口可属于事件跨度，但不属于复合异常。分别保留 `event_span_mask` 与实际超阈的 `event_mask`。
5. 在共同有效位置对单要素事件状态求逻辑 AND，得到各组合重叠。
6. 默认将逐片重叠直接送入追踪；显式指定复合持续条件时才额外筛选。复合缺口始终不填补，避免生成不存在的共现。
7. Ocetrac 默认在单层时使用 SurfTrack，在多层时使用 DeepTrack。适配层检查实际时间连续性，处理全球经度周期连接并记录对象间谱系；每个复合事件仍保留贡献的单要素 `source_event_ids`。
8. 统计事件指标，用实际受影响格点的单元边界生成 GeoJSON Polygon/MultiPolygon，保留边界中的孔洞。

允许单要素与复合持续要求分别配置：`--single-min-duration` 与 `--min-duration`。例如单要素均持续 5 天，仅在一天相交，可形成同时型，但不满足连续重叠 5 天的持续叠加型。

## 输出及指标口径

| 文件 | 内容 |
|---|---|
| masks.nc | 单要素阈值、有效掩膜、跨度与超阈状态；每组合有效、重叠、持续事件掩膜与对象编号 |
| events.json | 复合事件、起止日期、持续步数、来源单要素编号及各变量强度 |
| single_events.json | 本次计算使用的单要素事件目录 |
| events.geojson | 事件期间各深度受影响水平格点的空间并集边界 |
| tracks.geojson | 每个时间片的实际边界、质心、面积、体积及对象节点 |
| lineage.json | 逐片对象的延续、分裂、合并和跨尺度连接关系 |
| quality.json | 参数、共同覆盖、事件数量、LMF、统计支持及告警 |

掩膜为 0/1；必须同时查看有效掩膜。`valid_mask=0` 代表数据或阈值缺失，事件掩膜的 0 此时代表未知。

事件指标包括：

- `footprint_area_km2`：整个事件期间受影响水平格点的并集面积。
- `max_area_km2`：逐时间片计算水平面积后取最大值。
- `max_volume_km3`：逐时间片受影响体积的最大值。
- `summed_volume_time_km3_steps`：各时间片体积之和，单位为 km³·时间步，不能解释为瞬时体积。
- `metrics`：各变量原始最小/最大值、峰值超阈强度、按单元体积（或面积）加权的平均超阈强度、跨时间与空间求和的超阈量。
- `centroid`：按单元体积（或面积）加权的经纬度与深度中心。

网格面积按球面经纬度单元计算；单元边界由相邻格点中心推断。深度厚度使用相邻中心中点估计，不含显式海底/真实层边界；单个深度层时体积为 `null`。这是体积近似，不用于声称精确水体体积。累计超阈量也不是单格点的“强度×天数”。

空间 GeoJSON 是整个事件的水平足迹，不代表每一天的精确瞬时边界。瞬时分布应读取 `masks.nc` 的相应时间片。

`time_span` 保留月／日片数及实际时间支持区间；月均片不提供月内逐日连续性的证据。混合尺度时，新增的 `integrated_volume_km3_days` 等字段按真实区间长度加权，不能把 `duration_steps` 当成天数。

## LMF 与不确定性

双要素：`LMF = P(A∩B) / [P(A)P(B)]`。

三要素：`LMF = P(A∩B∩C) / [P(A)P(B)P(C)]`。

在同一组合的共同有效时间、深度、格点上计算各概率。事件状态来自已通过单要素持续条件的实际超阈单元，LMF 在复合持续筛选之前计算。双要素 LMF 始终采用包含第三要素的概率口径，即使输出事件配置为互斥双要素。

当前输出是区域汇总 LMF，会受到空间异质性影响，不能解释为每个格点的稳定依赖或生态协同损害。至少一个边际概率为零或没有共同有效支持时，LMF 为 `null`。

月／日混合输入分别输出各自的 LMF，不将不同时间单位的采样机会混合。

- 置信区间：保持整个空间场一起采样的循环移动时间区块自助法，默认区块长 5 步，200 次采样，输出 95% 区间。
- 置换检验：保留第一个变量，其余变量分别打乱时间区块；有效掩膜与事件状态一起移动，重新计算共同支持。默认 199 次，输出针对共现增强的单侧 p 值。
- 有效时间少于 3 个区块或 10 步时，不输出区间及 p 值。有效重复次数不足也不输出结果。
- 这些统计是平稳性假设下的探索性方法。时间长度、空间相关、季节变化和零事件样本均影响可信度。
- 固定 `--seed` 可复现区块采样和置换结果。

## 运行示例与已验证结果

安装：`python -m pip install -r data_processing/requirements.txt`。

### 两变量的实际数据流程验证

```bash
python -m data_processing.compound_detection \
  --input classroom/09_CMEMS分析预报BGC/cmems_bgc_nrt_bio_20240101_20240107_118-124E_24-30N_0-50m.nc \
          classroom/09_CMEMS分析预报BGC/cmems_bgc_nrt_car_20240101_20240107_118-124E_24-30N_0-50m.nc \
  --variables o2 ph --frequency daily \
  --threshold-mode absolute --threshold o2=245 --threshold ph=8.12 \
  --output data/processed/ocetrac_bgc_sample
```

2024-01-01 至 2024-01-07 的数据中，当前默认逐片识别＋Ocetrac 得到 4 个单要素候选对象及 1 个低氧＋高酸度复合候选对象。区域 LMF 约 1.293；由于仅 7 天，置信区间与置换 p 值均为 `null`。上述阈值为流程验证配置，不是通用生态阈值，也不是已经验证的科学发现。旧的三步持续筛选输出仍保留在原结果目录。

### 三变量的近期数据

```bash
python -m data_processing.cmems_preprocess \

          data/samples/bgc_anfc_o2_20260928.nc \

python -m data_processing.compound_detection \
  --input data/processed/compound_recent_input.nc \
  --variables thetao o2 ph --frequency daily \

  --threshold thetao=28 --threshold o2=205 --threshold ph=8.03 \
  --output data/processed/ocetrac_recent_sample
```

这些阈值同样仅用于演示流程。本地同期数据只有 2026-09-28 至 2026-09-29，现在可以进行逐片识别与追踪，不再因不足五天而全部排除。50 m 无有效值，仍保留缺测标记。旧的五天持续筛选零事件结果保留在原目录。

### 正式分析

在满足共同时间频率的长期、连续输入上指定真实基准期，使用 `--threshold-mode seasonal_percentile`、`--baseline-start`、`--baseline-end`。基准期和数据产品应一致。短样本不能替代长期气候基线。

月尺度使用 `--frequency monthly`，并调整单要素、复合持续步数，例如均为 1 或 2；这些步数代表月。
