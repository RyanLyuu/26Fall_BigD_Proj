# CMEMS 四类数据问题与预处理方案

本文总结当前已下载样本的检查结果，并给出进入复合极端事件分析前的统一预处理方案。

## 1. 当前样本

样本位于 `data/samples/`，覆盖东海附近 `122–123°E、27–28°N`，深度请求范围为 `0–50 m`。

| 文件 | 数据内容 | 时间 | 变量 |
|---|---|---|---|
| `glorys12_thetao_20240813.nc` | GLORYS12 历史物理再分析 | 2024-08-13 至 2024-08-14 | `thetao` |
| `bgc_my_o2_20240813.nc` | CMEMS 多年 BGC 日均 | 2024-08-13 至 2024-08-14 | `o2` |
| `bgc_my_o2_ph_202408.nc` | CMEMS 多年 BGC 月均 | 2024-08 | `o2`、`ph` |
| `phy_anfc_thetao_20260928.nc` | 全球物理分析预报 | 2026-09-28 至 2026-09-29 | `thetao` |
| `bgc_anfc_o2_20260928.nc` | BGC 分析预报 | 2026-09-28 至 2026-09-29 | `o2` |
| `bgc_anfc_ph_20260928.nc` | BGC 分析预报 | 2026-09-28 至 2026-09-29 | `ph` |

统一输出样本为：

- `data/processed/cmems_common.nc`
- `data/processed/cmems_common.quality.json`

## 2. 已发现的问题和解决方案

### 2.1 水平网格不一致

GLORYS12 和物理分析预报温度约为 `0.083°` 网格，BGC 和 BGC 预报为 `0.25°` 网格。当前样本分别返回 13×13 和 5×5 的空间网格。

如果直接逐格合并，温度与 BGC 变量并不对应同一个空间位置。把 BGC 插值到 0.083° 也不会增加真实空间信息。

**处理方案：**

- 以 BGC 的 0.25° 网格作为联合分析网格；
- 将 GLORYS12 和物理预报温度降采样到该网格；
- 连续变量使用线性或面积加权方法；
- 面积统计使用实际网格面积；
- 保留原始 0.083° 温度文件用于高分辨率展示。

当前模块会优先读取输入 BGC 网格中心，避免产生偏移的目标网格。

### 2.2 垂向层数和深度坐标不一致

当前样本都返回 18 个原生深度层，但实际深度坐标并不相同：

- GLORYS12 最浅层约为 `0.494 m`；
- BGC 最浅层约为 `0.506 m`；
- 原生层不是严格的 `0、10、20、50 m`；
- 原始最深层约为 `47.2–47.4 m`。

因此请求 `0–50 m` 并不代表数据一定覆盖严格的 50 m。

**处理方案：**

- 按实际深度坐标做垂向插值；
- 统一到 `1、5、10、20、30、40、50 m`；
- 不在有效深度范围外外推；
- 低于海底或原始最深层的值保留为缺测；
- 需要 50 m 时，下载最大深度建议设为至少 60 m；
- 在质量报告中记录每个变量每个深度的有效覆盖量。

当前模块已关闭垂向外推，并会报告无覆盖深度。

### 2.3 时间频率不一致

当前样本显示：

- GLORYS12 温度为日均；
- 多年 BGC `o2` 有日均数据；
- 多年 BGC `ph` 出现在月均数据中，样本只有 `2024-08-01` 一个时间点；
- BGC 分析预报的 `o2` 和 `ph` 都有日均数据。

如果把月均 pH 复制到每天，会制造不存在的日变化，影响复合事件持续时间判断。

**处理方案：**

- 日尺度分析使用日均温度、日均溶解氧和日均预报 pH；
- 多年历史 pH 若只有月均，则单独做月尺度分析；
- 不使用前向填充把月均 pH 扩展为日均；
- 所有时间统一为 UTC；
- 保留原始时间戳和时间频率；
- 历史分析、近期分析和未来预报分开标记。

当前模块保留各来源实际时间点，不会填充缺失日期。

### 2.4 同一变量来自多个产品

当前输入中，`thetao` 来自 GLORYS12 和物理分析预报，`o2` 和 `ph` 同时来自多年 BGC 与 BGC 分析预报。这些产品的模型、同化方式、时间覆盖和偏差不同，不能无标识地拼接成一条连续序列。

**处理方案：**

- 为每个变量保留来源产品标识；
- 历史、分析和预报来源分开记录；
- 重叠时间使用显式来源优先级；
- 默认保留命令行中先出现的来源；
- 可用 `--duplicate-policy last` 改为后出现来源优先；
- 在重叠时段计算产品间偏差；
- 复合事件优先使用相对于统一基线的异常值。

当前模块会对重复变量发出警告，并在质量报告中记录来源。

### 2.5 变量单位需要统一

实际样本单位为：

| 变量 | 样本单位 | 处理方案 |
|---|---|---|
| `thetao` | `degrees_C` | 保留为摄氏度位温 |
| `o2` | `mmol m-3` | 统一保留原始单位 |
| `ph` | `1` | 作为无量纲 pH 保留 |

不同观测数据可能使用 `μmol/kg` 或 `mg/L`。直接比较会导致阈值错误。

**处理方案：**

- 从 NetCDF 属性读取单位；
- 合并前检查同名变量单位是否兼容；
- 温度只使用 `thetao`，不与 SST 直接混合；
- 氧转换到 `μmol/kg` 时使用海水密度；
- pH 保留产品定义和总标度信息；
- 原始单位和标准化单位都写入元数据。

当前模块遇到不能安全转换的单位会直接报错。

### 2.6 缺测和海陆边界

原始样本中 GLORYS12 温度没有缺测，其他变量约有 `0.22%` 缺测。统一到 50 m 后，所有变量的 50 m 都因原始深度不足而无有效值。

**处理方案：**

- 将 `_FillValue` 和 `missing_value` 转成 `NaN`；
- 应用 `valid_min` 和 `valid_max`；
- 应用海陆和海底掩膜；
- 记录每个变量和深度的有效覆盖率；
- 设置最小有效覆盖阈值；
- 事件面积只使用有效海洋网格。

缺测不能当作 0，也不能在海陆边界大范围填补。

### 2.7 预报产品会滚动更新

分析预报产品会随着新一轮初始化更新，同一个日期的预报值可能发生变化。

**处理方案：**

- 保存下载日期和产品版本；
- 保存 `forecast_reference_time` 和 `lead_time`；
- 区分分析时段和预报时段；
- 自动任务使用 `--raise-if-updating`；
- 按 `lead_time=0、1、3、5、10 天` 评估预报质量；
- 不把预报值直接当成历史观测真值。

### 2.8 产品源的物理含义不同

GLORYS12 是物理再分析，多年 BGC 是生物地球化学 hindcast，物理分析预报和 BGC 分析预报又是独立系统。因此同一天的温度、氧和 pH 并不一定来自完全一致的模式状态。

**处理方案：**

- 四个产品作为独立来源保留；
- 只做统一坐标和时间对齐，不删除来源信息；
- 复合事件识别以异常值和共同基线为主；
- 不直接对跨产品原始值做无条件拼接；
- 使用 Argo、BGC-Argo、GLODAP 等观测做验证。

## 3. 当前预处理模块

相关文件：

- `data_processing/cmems_preprocess.py`
- `data_processing/requirements.txt`
- `data_processing/README.md`

默认配置：

```text
目标水平网格：输入 BGC 网格，通常为 0.25°
目标深度：1、5、10、20、30、40、50 m
空间插值：linear
垂向外推：关闭
缺测处理：NaN
重复时间：先出现的数据源优先
输出格式：压缩 NetCDF + JSON 质量报告
```

运行示例：

```bash
python -m data_processing.cmems_preprocess \
  --input data/samples/glorys12_thetao_20240813.nc \
         data/samples/bgc_my_o2_20240813.nc \
         data/samples/bgc_my_o2_ph_202408.nc \
         data/samples/phy_anfc_thetao_20260928.nc \
         data/samples/bgc_anfc_o2_20260928.nc \
         data/samples/bgc_anfc_ph_20260928.nc \
  --bbox 122 123 27 28 \
  --output data/processed/cmems_common.nc
```

## 4. 下一步分析流程

预处理模块只负责形成结构一致的数据立方体，不负责事件阈值和复合事件识别。下一步建议：

1. 选择固定气候基准期；
2. 计算温度、溶解氧和 pH 气候态；
3. 计算各变量异常值；
4. 用 P90/P10 或研究指定阈值识别单变量异常；
5. 按时间连续性和空间连通性提取事件；
6. 判断双要素和三要素复合事件；
7. 输出事件栅格、事件表和 GeoJSON；
8. 做阈值敏感性分析和观测验证。
