# 复合事件格点图：前端接入约定（待与分析服务对齐）

前端地图使用 `OceanGridFrame`（`src/types/index.ts`），最小水平格距为
0.25° × 0.25°，支持更粗网格。每个格点绘制为完整经纬度单元，边长来自
`resolutionDegrees`，单元中心来自后端 `longitude/latitude`。前端不将中心
吸附到另一套原点，不插值、不平滑，也不将网格裁成光滑事件多边形。海岸线使用独立的高精度陆地遮罩，避免沿岸单元覆盖陆地。

## 数据结构

```json
{
  "source": "analysis",
  "time": "2024-08-13",
  "resolutionDegrees": 0.25,
  "depthRange": [0, 50],
  "cells": [
    {
      "longitude": 122.125,
      "latitude": 27.125,
      "combination": "thetao_o2_ph",
      "eventIds": ["CE-001"],
      "affectedFraction": 0.75,
      "valid": true
    }
  ]
}
```

以上仅为字段示例，不是观测结果。`affectedFraction` 是 0–1 的水层受影响
比例，不能直接传入 0–100 的百分数。没有该指标时传 `null`；没有共同有效
支持时用 `valid: false`。有效但没有事件的格点用 `affectedFraction: 0`，
不绘制事件色块。`null` 不等同于 0；它使用类别中间色，悬浮提示占比待接入。
配色在 25%/50%/75% 三个锚点之间连续变化，低于 25% 和高于 75%
分别使用两端颜色；悬浮提示保留实际百分数。选中只描绘事件外缘，
消除相邻单元共享边，不改变数据填色。

组合键使用后端已有变量名：

| combination | 类别 | 色系 |
| --- | --- | --- |
| thetao_o2_ph | 高温＋低氧＋高酸度 | 灰 |
| thetao_ph | 高温＋高酸度 | 粉紫 |
| thetao_o2 | 高温＋低氧 | 橙 |
| o2_ph | 低氧＋高酸度 | 紫 |
| ph | 高酸度 | 绿 |
| o2 | 低氧 | 蓝 |
| thetao | 高温 | 红 |

每个水平格点在一个地图时间片中应有唯一的显示类别。三种双要素应与三要素
互斥，单要素也应排除其他异常。参考图将一个水柱压缩成一种颜色；如果同一
水柱不同深度属于不同类别，需要分析服务先明确主导类别规则与比例分母，
不能靠前端图层覆盖顺序决定。当前前端不会从事件总体深度范围推算水层比例。
缺失层、海底、真实层厚及显示深度范围由分析服务统一处理。

后端当前 `events.geojson` 表示整个事件期间、各深度的水平空间并集；它不等于
某一天的水柱占比。实际地图时间片需由对应时间的有效掩膜、事件掩膜及层厚
另行汇总，不把空间并集当成每日分布。参考图中的红色温度异常等值线也需要
真实异常场，当前不生成。

## 前端更新入口

服务调用层拿到并校验上述结构后，可以用
`useAnalysisStore.getState().set({ gridFrame: frame })` 替换地图数据。
网格几何与七类分级配色由 `src/lib/oceanGrid.ts` 和 `src/lib/eventLayers.ts`
转换。`eventIds` 应与事件摘要目录中的编号一致；后续接入真实事件目录时
同步替换当前本地事件数据，不能让真实格点指向无关的演示事件摘要。

当前没有新增 HTTP 接口或修改分析服务。运行分析按钮仍使用原来的演示流程。
默认 `source: demo`、`time: null` 的格点来自 `src/mock/grid-demo.json`，
是独立的合成演示，不是原演示事件的近似椭圆，也不是观测数据。使用确定性的
多尺度空间场生成三个要素在五层（5/10/10/10/15 m）中的布尔状态，
每层组合互斥；每个水柱按累计层厚最大的类别着色，并以该类别厚度 / 50 m
作为演示占比。平局先选要素数较多者，再按组合键稳定排序。
这套合成规则仅用于展示，不是分析服务应采用的科学聚合规则。

七类均有对应演示目录编号，日期、事件指标和时间曲线仍是原有演示内容，
地图不随日期/深度生成伪分析结果。页面图例明确显示“合成演示 · 非观测数据”，
悬浮显示“演示占比”。真实 `source: analysis` 数据完全绕开合成生成逻辑。

重建演示资源：安装离线工具所需的 Shapely 后运行
`python scripts/build-map-demo.py /path/to/ne_10m_land.geojson`。
输入为 Natural Earth 公共领域 1:10m 陆地数据；脚本同时生成高精度底图
和经陆地中心遮罩的演示格点，不读取或覆盖后端分析产物。

验证：`npm run test:grid` 检查实际中心与格距、缺失/零值区别、七类配色、
经度换日线、演示类别与占比范围、连续色阶和共享边消除；
`npm run build` 检查类型与打包。
